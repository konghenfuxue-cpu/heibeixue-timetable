# 黑背雪 · 每日课表

一个可在本地查看和调整课程的微信原生小程序；可选的PDF／图片自动识别需要部署微信云函数，基础课表功能无需服务器。打开即可查看当天课程、下一节课和整周安排，支持单双周、季节作息、假期补课以及个人调课。

本项目与绍兴大学有关，最初用于按绍兴大学的课程表和校历展示个人每日课程。项目使用“黑背雪”个人品牌，由个人维护，非绍兴大学官方小程序；公开版本供参考和自行适配。

公开版本使用虚构课程名称、教师与教室；内置的学期和校历规则仅供演示，请按自己的学校通知修改。仓库不包含原始课表 PDF、校历图片、真实 AppID 或本机个人调整数据。

## PDF／图片自动识别

在「设置 → 自动识别课表」选择文件。文字PDF优先提取，图片及扫描件可调用表格OCR。识别结果可逐条编辑；核对后确认保存，支持撤销和完整备份。云环境未配置时会提示部署，不会覆盖现有课程。

需先按 [云识别部署步骤](CLOUD_IMPORT.md) 开通微信云开发；OCR可能收费，不会自动开户或转入付费识别。当前支持此项目学期内的课表，校历不会随导入自动改写；支持格式和验证边界见部署说明。

## 功能

- 今日课程、实时上课状态与倒计时，每 30 秒在页面可见时刷新。
- 七日日期条、日期选择、明日预告。
- 七列整周课表，重叠课程合并展示，详情可逐门查看。
- 单次取消、移动课程、更换教室、整天停课与补课。
- JSON 备份、导入、最近一次导入撤销；支持文本和微信文件入口。
- 深墨蓝与雪白配色，个人标签“黑背雪”。

不提供后台通知或跨设备自动同步。调整记录保存在当前设备，清缓存或换设备前请导出并另存备份。

## 开始使用

1. 下载或克隆仓库，用微信开发者工具导入包含 `project.config.json` 的项目根目录。
2. `touristappid` 只是本地调试占位配置。手机预览使用自己的真实 AppID，或工具分配的测试号 AppID；按平台实际权限操作。
3. 编译后使用「今日」「整周」「设置」。发布与备案要求以微信平台当前要求为准。

本项目代码已经过原生 WXML/WXSS 编译检查；私人课表版本由用户确认手机页面正常显示。公开示例数据版本通过自动测试，文件分享与导入等操作仍建议在自己的手机上验证。

## 换成自己的课表

编辑 `miniprogram/data/courses.js` 的 `courses` 数组。每条排课记录需有唯一 `id`；同一门课的不同场次也要分配不同 ID。

```js
{
  id: 'c0', name: '高等数学',
  weekday: 1, start: 1, end: 2,
  first: 1, last: 17, parity: 'all',
  room: '教学楼101', teacher: '教师', campus: '主'
}
```

`weekday` 为 1—7（周一至周日），`start/end` 为节次，`first/last` 为教学周，`parity` 可取 `all`、`odd`、`even`。待安排课程放在 `pending` 数组。

编辑 `miniprogram/utils/schedule.js` 设置学期起止、作息、假期与补课规则。跨学期使用还需同步 `miniprogram/utils/backup.js` 中的 `TERM` 和日期校验范围；旧学期备份不会导入新学期。现有测试针对演示学期，改校历后应更新相应测试。

当前演示：2026-09-14 开学、2027-01-08 上课结束，5—9 月使用夏季作息、其他月份使用冬季作息；日期和实时状态按中国标准时间计算。

## 验证

安装 Node.js 20 或以上，基础自动测试无需安装依赖，在根目录运行：

```sh
npm test
```

覆盖日期与单双周、补课假期、冲突、单门调整、页面流程、WXML 表达式、备份格式与迁移。页面测试使用模拟微信接口，不能替代微信真机测试。
